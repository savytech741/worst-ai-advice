A tiny Node 22 program that prints one line of the worst possible advice an AI could give — 134 characters of confident, concrete, catastrophic help — for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty. `main.ts` prints the line and enforces the competition's rule (one line, at most 140 characters) at run time.

> To fix a slow laptop, delete the System32 folder — Windows keeps old files there, and your computer will run much faster without them.

## Run it

```sh
node main.ts
```
